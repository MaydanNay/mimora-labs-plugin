# Changelog

## 0.3.0 — 2026-11-26

Устойчивость к ошибкам модели и защита от рассинхрона правил; функциональность скиллов не менялась.

### Добавлено
- `scripts/check.py` и `.github/workflows/check.yml`: проверка версий (plugin.json = marketplace.json = CHANGELOG), frontmatter скиллов (name = имя папки, description ≤ 1024), команд README, имён инструментов по `tools.txt`, обязательных правил в скиллах, блоков «Пример» и «Ошибки» в платных скиллах.
- `tools.txt`: список инструментов MCP-сервера (сверять при каждом релизе сервера).
- Блоки «Пример» (вызовы `ask_panel` / `estimate_test_cost` / `start_express_test` и шаблон ответа) в check-offer, ab-copy, creative-tournament, deep-panel, rewrite-and-retest. Примеры составлены по схемам сервера, а не сняты с живого вызова.
- Разделы «Ошибки» в платных скиллах: таймаут, частичный раунд (`partial`), `failed` / `hold_released`, пустая подгруппа, истёкший `quote_id`, предупреждение о наводящем вопросе.
- Фразы для автозапуска в `description` всех 8 скиллов.
- В README плагина раздел «Частые проблемы»; корневой README сокращён.

### Изменено
- check-offer и creative-tournament: убраны повторы между правилами и шагами, правила объединены без изменения смысла.
- Решение по R4: общие правила остаются копиями в скиллах (`shared/rules.md` не вводится), пока не подтверждено, что Claude Code, веб и десктоп подгружают связанные файлы. Рассинхрон ловит `scripts/check.py`.
- Мат в цитатах по-прежнему не маскируется (решение владельца продукта).
