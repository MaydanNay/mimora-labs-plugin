# Mimora Labs Plugin

Плагин и маркетплейс **Mimora Labs** для Claude и других ИИ-ассистентов с поддержкой MCP и `SKILL.md`: 8 готовых сценариев проверки офферов, креативов, аудиторий и рекламных гипотез на ИИ-панелях (MCP-сервер `https://mcp.mimora.io/mcp`).

## Установка (Claude Code)

```bash
claude plugin marketplace add MaydanNay/mimora-labs-plugin
claude plugin install mimora-labs@mimora-labs
```

Затем в сессии откройте `/mcp`, выберите `mimora_labs` и авторизуйтесь.
